# ТЗ — Telegram-бот "Охотник за юзернеймами"

## Общая идея
Бот подбирает редкие свободные юзернеймы Telegram и оценивает их красоту.

## Функциональные требования

### 1. Поиск и фильтры
- Кнопка "Найти юзернейм" открывает меню фильтров.
- Фильтр по длине: 5 символов / 6 символов / 7 символов (и должна быть
  возможность расширять список фильтров дальше).
- Фильтр по цифрам:
  - без цифр
  - с цифрами
  - замена букв цифрами (leet: a→4, e→3, i→1, o→0 и т.п.)

### 2. Проверка занятости
- Проверять юзернейм на **Fragment**, чтобы убедиться, что он не занят.
- Занятые юзернеймы (пользователем, каналом или кем-либо ещё) — не
  показывать пользователю и не писать, что юз "недействителен". Просто
  молча пропускать и продолжать поиск дальше.

### 3. Оценка красоты
- Шкала красоты от 1 до 10.
- Для каждого найденного юзернейма показывать:
  - юз для копирования (обычным текстом)
  - тот же юз **отдельно моноширинным шрифтом** для удобного копирования
  - оценку красоты

### 4. Процесс поиска (UX)
- После выбора фильтров поиск запускается.
- Бот **обновляет одно и то же сообщение**, добавляя туда новый найденный
  юз с оценкой красоты (а не шлёт новое сообщение на каждую находку).
- Поиск идёт непрерывно, пока пользователь не нажмёт "Пауза" или "Стоп" в
  меню снизу (reply-клавиатура под полем ввода).

### 5. Управление поиском
- Кнопка "Пауза" — останавливает поиск, но его можно возобновить
  ("Продолжить").
- Кнопка "Стоп":
  - полностью останавливает поиск,
  - убирает все кнопки,
  - выводит итог: сколько юзернеймов найдено всего, и список этих юзов с
    оценками.

### 6. Оформление
- Во всём боте используется "прикольный" шрифт — не базовый обычный текст,
  но и не из стандартных вариантов форматирования Telegram (не обычный
  bold/italic) — то есть unicode-шрифты.
- Сами юзернеймы шрифтом не украшаются (иначе их нельзя будет реально
  использовать/скопировать как настоящий ник).

### 7. Качество
- Сделать без багов, не торопясь.
- В конце — прислать весь код.

## Как реализовано (кратко)
- Framework: aiogram 3.x (Python, async).
- Проверка занятости — гибридная: `t.me/<username>` (основной надёжный
  источник) + `fragment.com/username/<username>` (доп. подтверждение, как
  и просили). Юз считается свободным, только если оба источника согласны;
  при неопределённости — юз просто пропускается.
- Генератор юзернеймов — по слогам (чередование согласная/гласная) для
  более "живых" и произносимых вариантов, с точным соблюдением заданной
  длины во всех режимах (включая режим "с цифрами").
- Оценка красоты — эвристическая формула (длина, произносимость, повторы,
  уникальность символов, палиндромы, последовательности, аккуратность
  использования цифр).
- Шрифты — unicode Mathematical Alphanumeric Symbols (Sans-Serif Bold /
  Italic / Script) + шкала звёзд и "круглые" цифры для оценки.
