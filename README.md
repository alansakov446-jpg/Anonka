# Охотник за юзернеймами — Telegram-бот

**Текущая версия: 1.5.0**

Бот подбирает свободные редкие юзернеймы Telegram (от 5 символов, с фильтрами
по цифрам/leet-заменам), **жёстко параллельно** проверяет их через официальный
Bot API и Fragment (с обходом Cloudflare через `cloudscraper`), оценивает
читаемость/красоту по шкале 1–10 и хранит всю историю находок в Supabase
(PostgreSQL) с автоматическим фоллбэком на локальный SQLite.

## Что нового в v1.5.0

- **Переход на Supabase (PostgreSQL)** через `asyncpg` + `DATABASE_URL`. Если
  подключения нет или переменная не задана — бот безопасно падает на
  `bot_data.db` (SQLite). Старая SQLite-схема подхватывается без миграций,
  ничего не теряется.
- **Параллельная проверка** (`CONCURRENCY` воркеров через `asyncio.Queue`) —
  скорость выросла с ~50 юз/мин до 200+ (настраивается).
- **Жёсткая проверка**: юз считается свободным ТОЛЬКО если и Bot API
  (`getChat` → `Chat not found`), И Fragment не сигнализирует об активном
  аукционе/продаже. Плюс отсеивается большой список зарезервированных/служебных
  имён (`telegram`, `support`, `bot`, `admin`, паттерны `*telegram*`, `tgm*`…).
- **Пагинация «живого» сообщения** со стрелками ◀️ ▶️ при переполнении
  (ограничение Telegram ~4096 символов, бот держит запас и сам разбивает
  находки на страницы по 6 штук).
- **Пауза / Продолжить / Стоп** через reply-клавиатуру. Пауза не сбрасывает
  сессию, можно возобновить.
- **Меню `/start` с тремя кнопками**: 🔍 Поиск / 📜 История / ⚙️ Настройки.
- **Фильтры перед поиском**: длина (5/6/7/5–7) × режим цифр (без цифр / с
  цифрами / leet-замена букв на похожие цифры).
- **Статус в реальном времени**: проверено/найдено, скорость юз/мин,
  зарезервированные, индикатор доступности Fragment.
- **Оценка красоты 1–10** улучшена: ритм (чередование гласных/согласных),
  штраф за кашу из 3+ согласных, бонус за произносимые диграфы, штраф за
  цифры/подчёркивания, баланс гласных, штраф за три одинаковых подряд,
  небольшой бонус палиндромам.
- **Калибровка под пользователя**: до 25 шагов, с **5-го шага** доступна
  кнопка «⚡ Завершить калибровку сейчас».
- **Настройки**: лимит проверок за прогон (500/1000/2500/5000/10000/∞),
  тумблеры «Без моноширинного», «Точный юзер (чистый текст)», «Тихий режим»,
  кнопка «🔄 Пройти калибровку заново».
- **Экспорт истории** в TXT и JSON прямо из меню истории.
- **Формат каждой находки**: `@username`, ниже моно-версия в `<code>` с
  оценкой, ниже ссылка на Fragment для ручной проверки.

## Быстрый старт

```bash
git clone https://github.com/alansakov446-jpg/Anonka
cd Anonka
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# Вставь BOT_TOKEN и (опционально) DATABASE_URL в .env
python bot.py
```

## Переменные окружения (.env)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `BOT_TOKEN` | — | Токен из @BotFather (обязательно) |
| `DATABASE_URL` | — | PostgreSQL DSN от Supabase (если не задан — локальный SQLite) |
| `CONCURRENCY` | `5` | Количество параллельных проверок |
| `CHECK_DELAY_SECONDS` | `0.25` | Пауза между проверками в одном воркере |
| `PAGE_SIZE_LIVE` | `6` | Находок на странице в сообщении поиска |
| `PAGE_SIZE_HISTORY` | `10` | Находок на странице в истории |
| `PROXY_URL` | — | Опциональный HTTP-прокси |

## Структура файлов

- `bot.py` — точка входа, цикл polling, все хэндлеры, мульти-воркерный поиск, пагинация.
- `config.py` — чтение env / константы.
- `storage.py` — Supabase (asyncpg) + фоллбэк SQLite, настройки/калибровка/история.
- `checker.py` — проверка доступности через Bot API + Fragment (cloudscraper).
- `beauty.py` — оценка красоты 1–10, leet-варианты, зарезервированные юзы, веса калибровки.
- `keyboards.py` — все inline/reply клавиатуры (меню, фильтры, пагинация, настройки, калибровка).
- `username_gen.py` — генератор «читаемых» юзернеймов по фильтрам.
- `fancy_font.py` — unicode-шрифты для заголовков (НЕ применяются к самим юзам).
- `app.py` — точка входа для Hugging Face Spaces (Gradio-статус + бот в фоне).

## Запуск на Hugging Face Spaces / Render / VPS

См. инструкции в `TZ.md`. Бот сам сбрасывает вебхук перед стартом polling и
следит за живым соединением; Gradio-обёртка `app.py` нужна только для HF Spaces.
